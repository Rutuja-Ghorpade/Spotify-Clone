🎧 Spotify Clone

This project replicates the design of Spotify using HTML, CSS, and Bootstrap, focusing on a responsive layout with interactive controls.

🔧 Technologies Used

HTML – For structuring the web pages

CSS – For styling, Flexbox/Grid for responsiveness

Bootstrap – For easy styling and responsive design

📐 Layout and Design

Fixed Sidebar – For navigation Spotify’s main menu

Main Area – Displays playlists and song details

Music Player – Features interactive controls for play/pause, volume, etc.

✨ Key Features

Responsive Design – Adapts to various screen sizes using Flexbox/Grid and Bootstrap.

Interactive Controls – Button transitions and hover effects using CSS.

Planned Updates – Future integration of JavaScript for enhanced music player functionality.

🧠 Purpose

To create a visually similar version of Spotify with a focus on layout and user interaction. This is a front-end project aimed at improving web design and responsiveness skills.
